# Learning Note Template

### Command Instructions

**Update daily log**

```bash
npm run log
```

**Update minor version**

```bash
npm run release
```

**Merge updates into `main` (run on the `develop` branch)**

```bash
npm run update
```

### Git Flow

1. Run `npm run log` (on the `develop` branch).
2. Run `npm run release` (on the `develop` branch).
3. Run `npm run update` (on the `develop` branch).
